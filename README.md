# Photography websites

Static websites for photography studios in Tamil Nadu, by Santhosh Kumar.

| Folder | Site |
|--------|------|
| `lightson/` | LightsOn Photography, Puthur, Trichy (see `lightson/README.md`; older versions in `lightson/versions/`) |
| `bigshots/` | Big Shots Photography, Tamil Nadu: Wedding Packages 2026 demo, built on the LightsOn template |

The root `index.html` links to both. No build step: every folder is plain HTML, CSS and JS with self-hosted fonts, served as-is by GitHub Pages.

## Big Shots notes

- Package names, prices, coverage and deliverables are copied exactly from the studio's 2026 price poster.
- All photos in `bigshots/img/` are marked placeholders. To add the studio's photos, replace each file with a real photo of the same name in three sizes: `name.webp` (1440×1800), `name-m.webp` (960×1200) and `name-s.webp` (480×600).
- The "How booking works" wording and the Tamil text are drafts for the studio to confirm.
